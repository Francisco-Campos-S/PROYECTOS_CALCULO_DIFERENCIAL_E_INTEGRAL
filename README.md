# Proyectos de Cálculo Diferencial e Integral

Repositorio académico de los proyectos aplicados del curso **MA-0321 Cálculo Diferencial e Integral**, de la Escuela de Matemática de la Universidad de Costa Rica, II ciclo 2026.

## Contenido del repositorio

El repositorio reúne dos proyectos aplicados que utilizan herramientas de cálculo para analizar situaciones reales, construir modelos matemáticos e interpretar resultados para apoyar decisiones.

| Proyecto | Descripción | Documentación |
| --- | --- | --- |
| Proyecto 1 | Aplicaciones de derivadas, límites y optimización en problemas empresariales. | [Abrir Proyecto 1](PROYECTO_1/README.md) |
| Proyecto 2 | Modelación con integración para resolver problemas de decisión a partir de datos entregados. | [Abrir Proyecto 2](PROYECTO_2/README.md) |

## Proyecto 1

El primer proyecto reúne trabajos grupales sobre aplicaciones del cálculo diferencial e integral en contextos empresariales. Entre los temas desarrollados se encuentran:

- Simuladores de ahorro e inversión.
- Inventario óptimo y utilidad neta.
- Tarifas por tramos y demanda.
- Crecimiento de usuarios y planificación de capacidad.
- Capacidad de servidores y costo marginal.

Cada grupo cuenta con su propia carpeta, README, código, informe y archivos de datos cuando corresponde.

Consulta la documentación completa en [PROYECTO_1/README.md](PROYECTO_1/README.md).

## Proyecto 2

El segundo proyecto contiene diez entregas individuales de modelación con integración. Cada estudiante presenta un informe PDF y una hoja de cálculo con los datos y cálculos utilizados.

Los casos estudian fenómenos como somnolencia al volante, amenaza sísmica, gases volcánicos, migración de aves, estrés térmico, energía de las olas y producción eólica, entre otros.

Cada entrega incluye un README individual con el tema asignado, el objetivo, el desarrollo general, los archivos y las instrucciones para revisar el trabajo.

Consulta la documentación completa y el índice de estudiantes en [PROYECTO_2/README.md](PROYECTO_2/README.md).

## Cómo utilizar el repositorio

1. Seleccionar el proyecto que se desea revisar.
2. Leer el README correspondiente para conocer su propósito y organización.
3. Entrar en la carpeta del grupo o estudiante de interés.
4. Consultar el informe, el código, los datos o la hoja de cálculo disponibles.
